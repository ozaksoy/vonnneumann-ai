Runtime Interface Concept

Declarative agent definition with explicit latency bounds and context isolation.

agent_runtime.py
Python 3.11+ 
from vonnneumann import AgentRuntime, ExecutionContext

runtime = AgentRuntime(isolation="strict-sandbox")

@runtime.register(name="ReasoningNode")
async def handle_step(ctx: ExecutionContext):
    # Compiles prompt graph into minimal payload for Anthropic API
    result = await ctx.execute(
        provider="anthropic",
        structured_output=True,
        max_overhead_target_ms=100
    )
    return result.stream()

Project FAQ

Details on our early-stage roadmap and architecture goals.

What is the current status of Vonn Neumann AI?

Why focus specifically on Anthropic models?

Anthropic's models excel at complex reasoning and function calling. Our architecture is optimized to leverage prompt caching and low-latency API patterns provided by Anthropic.
