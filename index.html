Native Anthropic Integration

How Vonn Neumann orchestrates Claude API calls with prompt caching & isolated state sandboxes.

anthropic_orchestrator.py
Claude Sonnet 5.5 
import anthropic
from vonnneumann import AgentStateRouter

client = anthropic.AsyncAnthropic()
router = AgentStateRouter(cache_ttl_sec=300)

async def run_claude_agent(prompt: str, context: dict):
    # Direct Anthropic API call with Prompt Caching
    response = await client.messages.create(
        model="claude-sonnet-5-5",
        max_tokens=1024,
        system=[{
            "type": "text",
            "text": router.get_cached_system_prompt(),
            "cache_control": {"type": "ephemeral"}
        }],
        messages=[{"role": "user", "content": prompt}]
    )
    return router.process_agent_state(response)

Project FAQ

Details on the early-stage roadmap and architecture goals.

What is the current status of Vonn Neumann AI?

A personal, non-commercial experimental project in developer preview, building core orchestration primitives for Anthropic Claude workflows.

How does Vonn Neumann leverage Claude Prompt Caching?

The state router is designed to cache shared agent system instructions with Claude prompt caching, reducing latency and input token cost across repeated agent calls.
